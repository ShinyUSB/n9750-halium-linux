# Patches

## kernel/
Generated by diffing the working tree (`ShinyKernel-gpu-exp/Kernel`) against the baseline
Samsung lineage tree (`ShinyKernel/Kernel`), build outputs excluded.

- `01-display-d2q.patch` — display/D2Q group (msm_atomic, msm_fbdev, dsi_display DMS
  re-enable, dsi_drm priv_info fallback, sde_kms d2q_dsi_crtc, mdss-dsi-pll-7nm digital-top,
  drm_vblank non-fatal WARN).
- `03-other.patch` — the a6xx GMU/HFI GPU port, msm_drv/GPU plumbing, IPA, service-locator,
  watchdog_v2, touch (sec_ts), wacom, DTS + defconfig, gcc-wrapper.
- `per-file/` — one diff per changed file, for review.
- `reference/` — the current msm_atomic.c / msm_fbdev.c / msm_drv.h **including the
  experimental atomic-commit kick** (`d2q_kick_arm` / `d2q_kick_active`). NOTE: that
  experiment (images 308/309) DEADLOCKS: the kick's commit blocks on `connection_mutex`
  held by the primary commit in `sde_kms_prepare_fence`, wedging the DRM pipeline. It is
  kept for reference; do not ship it.

All per-file patches pass `patch -p1 --dry-run` against the baseline tree.

## mesa/
Deltas of the kgsl Mesa fork vs pristine upstream Mesa 25.3.0:
- `01-tu-kgsl.patch` — Turnip kgsl winsys: non-ETIMEDOUT error handling (EINTR/EAGAIN).
- `02-zink-screen.patch` — zink screen tweaks for the kgsl device.
- `03-dril-target.patch` — DRIL dispatcher: allow per-driver selection on this fork
  (the fork ships no msm pipe driver; compositors must use the DRM dumb allocator).

## misc/
`ns-lite-v2-to-v3.diff` — QRTR name-service: instance-filtered lookups/pushes (the fix that
stops the kernel's SERVREG listener from binding to the wrong subsystem).
